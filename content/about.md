Hi, I'm Dmitry Yakimenko, a software and reverse engineer.

Most of my work is figuring out how closed systems work and building software that talks to them. For years I've been taking apart password managers like 1Password, Bitwarden, LastPass and Dashlane and turning what I find into open source client libraries in C#, Ruby, C++ and Rust. Besides that I write backend code and tools in Go.

I'm available for freelance work: reverse engineering protocols and file formats, integrations with services that don't offer a public API, and backend development. I work with [Bitwarden](https://bitwarden.com), [Devolutions](https://devolutions.net) and other clients. Write to [detunized@gmail.com](mailto:detunized@gmail.com).
