Hi, I'm Dmitry Yakimenko. I'm a software and reverse engineer, a dad of two and sometimes a photographer.

## What I work on

Most of my open source work is about getting data out of password managers. [Password Manager Access](https://github.com/detunized/password-manager-access) is a .NET library with read-only access to 1Password, Bitwarden, Dashlane, LastPass, Proton Pass, RoboForm, Sticky Password, True Key and Zoho Vault. It replaced a bunch of smaller libraries I wrote before it, like [lastpass-ruby](https://github.com/detunized/lastpass-ruby), [lastpass-sharp](https://github.com/detunized/lastpass-sharp), [1password-sharp](https://github.com/detunized/1password-sharp) and [dashlane-sharp](https://github.com/detunized/dashlane-sharp). The rest is on [GitHub](https://github.com/detunized).

## The name

0xDEADBEEF is a classic hex magic number. Debuggers and memory allocators write it into freed or uninitialized memory, so it stands out in a dump. That's also why the front page looks like one.
